# Bismillah wall piece — 3D and AR preview

Interactive 3D viewer for a laser-cut steel Bismillah wall piece, with a "View on your wall" AR button
(Android Chrome via Scene Viewer / WebXR, iPhone Safari via Quick Look). Built with
[model-viewer](https://modelviewer.dev/).

- `bismillah_120cm.glb` — real-scale model (120 × 22.5 cm, 3 mm), back face on the wall plane
- `bismillah_120cm.usdz` — the same model for iOS Quick Look
